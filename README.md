
# Week 3 - Data Wrangling

## Project Overview
This project focuses on cleaning and analyzing workout data using Python and Pandas.

## Tasks Completed
- Loaded the dataset using Pandas.
- Checked the dataset structure and missing values.
- Handled missing values in Date and Calories.
- Identified and removed duplicate rows.
- Filtered workouts with more than 400 calories.
- Created a new Intensity column based on Pulse.
- Created a bar chart using Matplotlib.
- Saved the cleaned dataset as cleaned_data.csv.

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Final Dataset
The cleaned dataset contains 30 rows and 6 columns, including the new Intensity column.

## Visualization
A bar chart displays the number of workouts classified as High or Normal intensity.
